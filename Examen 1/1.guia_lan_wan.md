# 🌐 Guía Básica de Redes LAN y WAN - Cisco Packet Tracer

## 📘 Introducción

Esta guía explica el funcionamiento básico de redes LAN y WAN pequeñas utilizando Cisco Packet Tracer.

También muestra cómo cambian las redes dependiendo de la máscara de subred y cómo configurar dispositivos básicos como:

- PCs
- Switches
- Routers

Además, se explica el uso de rutas estáticas con `ip route`.

---

# 🖥️ ¿Qué es una Red LAN?

Una LAN (Local Area Network) es una red local utilizada dentro de:

- Casas
- Escuelas
- Oficinas
- Laboratorios

## Ejemplo

```text
PC1 ---- Switch ---- Router
PC2 ----/
PC3 ----/
```

Las redes LAN normalmente utilizan switches para conectar dispositivos dentro de la misma red.

---

# 🌍 ¿Qué es una Red WAN?

Una WAN (Wide Area Network) conecta redes LAN ubicadas en diferentes lugares.

## Ejemplo

```text
[LAN 1] ---- Router ---- Router ---- [LAN 2]
```

Las conexiones WAN normalmente utilizan enlaces entre routers.

---

# 🧠 ¿Qué es una Dirección IP?

Una dirección IP identifica un dispositivo dentro de una red.

## Ejemplo

```text
192.168.1.10
```

Cada dirección IP se divide en:

- Parte de RED
- Parte de HOST

La máscara de subred determina qué parte pertenece a la red y cuál pertenece al host.

---

# 🎭 ¿Qué es una Máscara de Subred?

La máscara de subred define:

- Cuántas redes pueden existir
- Cuántos dispositivos puede tener cada red

---

# 📚 Máscaras Comunes

| Máscara | CIDR | Hosts |
|---|---|---|
| 255.255.255.0 | /24 | 254 |
| 255.255.255.128 | /25 | 126 |
| 255.255.255.192 | /26 | 62 |
| 255.255.255.224 | /27 | 30 |
| 255.255.255.240 | /28 | 14 |
| 255.255.255.248 | /29 | 6 |
| 255.255.255.252 | /30 | 2 |

---

# 🔥 Fórmula para Calcular Hosts

```text
2^(32 - CIDR) - 2
```

## Ejemplo `/24`

```text
2^(32 - 24) - 2
2^8 - 2
256 - 2
254 hosts
```

## Ejemplo `/30`

```text
2^(32 - 30) - 2
2^2 - 2
4 - 2
2 hosts
```

---

# 📌 ¿Cómo cambia una red dependiendo de la máscara?

La máscara modifica:

- El tamaño de la red
- La cantidad de hosts disponibles
- El rango de IPs
- La cantidad de subredes

---

# ✅ Ejemplo 1: Red `/24`

## Configuración

```text
IP:        192.168.1.10
Máscara:   255.255.255.0
CIDR:      /24
```

## Resultado

| Elemento | Valor |
|---|---|
| Dirección de red | 192.168.1.0 |
| Broadcast | 192.168.1.255 |
| Hosts disponibles | 254 |

## Rango de Hosts

```text
192.168.1.1 → 192.168.1.254
```

---

# ✅ Ejemplo 2: Red `/26`

## Configuración

```text
IP:        192.168.1.10
Máscara:   255.255.255.192
CIDR:      /26
```

## Resultado

| Elemento | Valor |
|---|---|
| Dirección de red | 192.168.1.0 |
| Broadcast | 192.168.1.63 |
| Hosts disponibles | 62 |

## Rango de Hosts

```text
192.168.1.1 → 192.168.1.62
```

---

# 🚨 Diferencia entre `/24` y `/26`

| Característica | /24 | /26 |
|---|---|---|
| Hosts disponibles | 254 | 62 |
| Tamaño de red | Grande | Más pequeña |
| Cantidad de subredes | 1 | 4 |
