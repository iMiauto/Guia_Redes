# 🖥️ Configuración de una PC

Las PCs normalmente se configuran desde la interfaz gráfica.

## Pasos

1. Seleccionar la PC
2. Ir a:
   - Desktop
   - IP Configuration
3. Configurar:
   - IP Address
   - Subnet Mask
   - Default Gateway

---

# ✅ Ejemplo

| Parámetro | Valor |
|---|---|
| IP Address | 192.168.1.10 |
| Subnet Mask | 255.255.255.0 |
| Default Gateway | 192.168.1.1 |

---

# 🔀 Configuración Básica de un Switch

Los switches normalmente utilizan una IP de administración.

## Configuración

```bash
enable
configure terminal

interface vlan 1
ip address 192.168.1.2 255.255.255.0
no shutdown

exit

ip default-gateway 192.168.1.1
```

---

# 🌐 Configuración Básica de un Router

Los routers utilizan interfaces físicas para conectarse a diferentes redes.

---

# 🔌 Configuración de Interfaz GigabitEthernet

```bash
enable
configure terminal

interface gigabitEthernet 0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

exit
```

---

# 🌍 Configuración WAN entre Routers

  NO OLVIDAR PONERLE EL MÓDULO HWIC-2T A LOS ROUTERS
## Router 1

  

```bash
enable
configure terminal

interface serial 0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
no shutdown

exit
```

---

## Router 2

```bash
enable
configure terminal

interface serial 0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown

exit
```

---

# ⚠️ Uso de `clock rate`

El comando:

```bash
clock rate 64000
```

solamente se utiliza en el router que tiene el cable DCE.

---

# 🌍 Rutas Estáticas - `ip route`

Cuando existen varios routers, cada router solamente conoce las redes conectadas directamente.

Para que todos los routers puedan comunicarse, se utilizan rutas estáticas.

---

# 🧠 Sintaxis

```bash
ip route [RED_DESTINO] [MÁSCARA] [SIGUIENTE_SALTO]
```

---

# 🧪 Configuración Completa

---

# 🔹 Router R1

```bash
enable
configure terminal

hostname R1

interface gigabitEthernet 0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

interface serial 0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
no shutdown

ip route 192.168.2.0 255.255.255.0 10.0.0.2
```

---

enable
configure terminal

interface gigabitEthernet 0/0

no shutdown

ip address 10.0.0.2 255.255.255.252
no shutdown

ip route 192.168.1.0 255.255.255.0 10.0.0.1

---

# ⚠️ Errores Comunes

## ❌ Olvidar `no shutdown`

La interfaz permanece apagada.

---

## ❌ Gateway incorrecto

No existe comunicación fuera de la red.

---

## ❌ Máscara incorrecta

Los dispositivos creen estar en redes diferentes.

---

## ❌ IP repetida

Dos dispositivos utilizan la misma IP.

---

## ❌ Rutas faltantes

Los routers no conocen redes remotas.
